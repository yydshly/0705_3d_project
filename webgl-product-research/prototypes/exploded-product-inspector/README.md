# 假相机零件检视

一个独立的小网页。屏幕中间是一台用方块和圆柱搭出来的假相机，可以旋转、拉开、点选零件。

它用来证明这几件事：

- 四个零件能沿固定方向分开，再回到原位
- 点中某一块后，高亮、侧栏说明、镜头会一起换成那一块
- 「复位」会同时收回零件和机位

模型是程序生成的，不是真实产品文件。

## 怎么跑

```powershell
cd webgl-product-research/prototypes/exploded-product-inspector
npm install
npm run dev
```

打开终端里的本地地址。默认是 `http://127.0.0.1:5180/`。

## 怎么操作

- 拖拽画面旋转，滚轮拉近或拉远
- 「拉开」把机身、镜头、快门、电池仓分开
- 「合上」让零件回到合拢的位置
- 点击任意零件，查看右侧说明
- 「复位」回到一开始的机位、合拢状态和「整机」说明
